Aide - Outil HMH de segmentation LSF

Retour a l'outil

But de l'outil

Cet outil sert a envoyer une grande video de langue des signes sur le PC serveur, detecter les moments ou la main travaille, couper la video en un clip par signe, puis produire un fichier JSON COCO-style par clip avec les keypoints MediaPipe.

Tout le calcul se fait sur le PC qui lance le serveur Python, pas sur l'ordinateur de la personne connectee.

Workflow recommande

  1. Dans Source, choisis une video. Elle est uploadee dans workspace/uploads/ sur le serveur.
  2. Verifie l'overlay des mains. La main utilisee est coloree, les autres sont grisees.
  3. Regle Labels des mains. Si la main droite du signeur apparait comme gauche, choisis Inverser Left/Right.
  4. Garde en general Main detectee: Droite seulement et Cote a garder: Cote gauche.
  5. Clique sur Scanner la video.
  6. Corrige les segments si besoin, puis clique sur Exporter les clips.
  7. Clique sur Extraire JSON COCO, puis telecharge le ZIP des JSON.

Comprendre les reglages main droite/gauche

MediaPipe renvoie les labels Right et Left. Selon la camera et l'effet miroir, le label peut ne pas correspondre a ce que tu vois a l'ecran. L'overlay affiche donc le label corrige, le label brut si different, et le cote ecran left ou right.

Pour un dataset normalise sur la main droite du signeur visible a gauche de l'ecran, utilise : Droite seulement + Cote gauche. Pour les JSON : Main: Right + Cote: Gauche.

Dossiers serveur

  • workspace/uploads/ : videos envoyees par les utilisateurs.
  • workspace/clips/ : clips coupes par le serveur.
  • workspace/keypoints/ : JSON COCO-style generes par MediaPipe.

Ces dossiers ne sont pas envoyes sur GitHub.

Si le scan rate des signes

  • Monte un peu Marge avant et Marge apres si les clips sont trop courts.
  • Descends Points minimum au-dessus si la main est souvent partiellement detectee.
  • Augmente Pause pour fermer le signe si un meme signe est coupe en plusieurs clips.
  • Verifie d'abord Labels des mains et Cote a garder avec l'overlay.
